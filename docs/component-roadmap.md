# Component Roadmap

## Tier 1 (Critical)
These components form the foundation of all ERP workflows, ensuring high data density, stable forms, and core navigation.
* Button
* Input
* Select
* Card
* Badge
* Table

## Tier 2 (Important)
These components provide advanced user feedback and complex interaction layers necessary for professional SaaS applications.
* Dialog
* Drawer
* Toast
* Tooltip
* Alert

## Tier 3 (Future)
These components unlock power-user efficiency and customize the ERP experience for specific workflows.
* Command Palette
* Advanced Filters
* Bulk Action Bar
* Saved Views
